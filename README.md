## 배포 및 문서 관리

- `main` 브랜치에 푸시하면 `https://cjy.app`에 자동 배포됩니다.
- 문서 시행일: 2026년 11월 10일.
- 문서는 핵심 내용 중심으로 정리했으며, 미확정 상세와 초안 안내는 공개 본문에서 제외했습니다.
- 검색엔진 `noindex` 설정은 유지합니다.
- `/`와 `/privacy/`의 본문은 동일하게 관리합니다.
- `.backups/`와 `dist/`는 Git에 포함하지 않습니다.

근거와 앱 선언의 상세 대응표: OnMap 프로젝트 `Docs/PRIVACY_DATA_AUDIT.md`.
